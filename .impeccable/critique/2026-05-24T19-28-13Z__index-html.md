## Anti-Patterns Verdict

Not first-order AI slop (no glassmorphism, no gradient text, no card grid). Second-order: reads as "minimal developer portfolio template" — the saturated lane by 2026. Tiny uppercase tracked labels on every section, system font, pure neutrals, centered narrow column. No POV.

Detector: #888 on #fff = 3.5:1 (WCAG AA fail). Helvetica and Arial overuse warnings. One cross-theme false positive.

## Priority Issues

[P1] H1 at 1.1rem — name has no visual weight. Fix: clamp(2.5rem, 6vw, 5rem). Command: /impeccable typeset
[P1] System font stack (Helvetica/Arial) — no voice. Fix: pick a custom font deliberately. Command: /impeccable typeset
[P1] #fff/#111 untinted, #888 muted fails contrast at 3.5:1. Fix: tint neutrals to brand hue, darken muted to #6b6b6b+. Command: /impeccable colorize
[P2] Repeated tiny uppercase tracked labels — brand ban. Fix: differentiate section headings or commit fully to named system. Command: /impeccable layout
[P2] Work/Projects sections lack context — no roles, no dates, no descriptions. Fix: add role+tenure to Work; add 1-2 sentence descriptions to Projects. Command: /impeccable clarify
